# Apex Game Icon Resource

apex_game_icon.png is the monochrome black, transparent-background game icon used to generate the Windows application icon. It is the standalone geometric Apex emblem, without the APEX or LEGENDS wordmark.

Source: https://commons.wikimedia.org/wiki/File:APEX_legends_logo_mini.png

The source page lists the image as public domain and credits Electronic Arts. The Apex Legends name and logo remain the property of their respective owners.

The generated Windows ICO is ../../windows/runner/resources/app_icon.ico. Both the Flutter Windows runner and the Inno Setup installer reference that file.
